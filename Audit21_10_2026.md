### A4. HUD ломается навсегда после поворота телефона

- **Где:** `RojoTest/src/client/Modules/HudLayout.luau`

- **Измерено в Studio:** `before` = все элементы `true` → после портрета все `false` → **после обратного переключения в ландшафт всё остаётся `false`**
- **Теряется:** кнопки магазина в HUD, покупки скилла (+10M/+100M/+1B), подпись «ONLY ◉ 25» и иконка на кнопке авто-броска

- **Что делать:** при смене раскладки явно сбрасывать состояние — `visible` для элементов, не помеченных скрытыми в новой спеке, должен становиться `true`; `hide` очищается перед применением новой спеки; оверрайды подписи сбрасываются

### A7. Baseline склеивает разные ошибки — новые находки маскируются

- **Где:** `RojoTest/tools/check.mjs:153-168`
- **Причина:** ключ = `файл|вид|head`, где `head` обрезан по первому `{`/`(`/`[`/`<`, а номер строки выброшен намеренно. Коллизии ключей внутри одного файла:

  | Файл | Реальных ошибок | Уникальных ключей |
  |---|---|---|
  | `shared/GameConfig.luau` | 176 | **8** |
  | `client/NativeIcons.luau` | 240 | **5** |
  | `server/PolarExpeditionScenery.luau` | 360 | 32 |
  | `server/SakuraJapaneseScenery.luau` | 282 | 35 |
  | `server/MapPolish.luau` | 222 | 19 |

- **Следствие:** head `"Expected this to be exactly"` уже покрывает 22 находки в `GameConfig.luau`; **новая** ошибка с тем же head в этом же файле не будет отмечена как регрессия. То же для `"Argument count mismatch. Function 'shape' expects 8 arguments, but only 7 are specified"` (216 находок → 1 ключ)
- **Почему номер строки убрали:** иначе вставка строки над известной ошибкой выглядит как новая находка (luau-lsp решает free-type по hash-порядку Rust, приём проверен, см. `skills/roblox-code/references/traps.md`)
- **Что делать:** найти баланс — ключ по `(file, kind, message)` с нормализацией выведенных типов (вместо грубого обрезания по первой скобке) и без номера строки; либо включить номер строки и тогда чинить free-type аннотациями

в тот же день. Гейт: `node RojoTest/tools/check.mjs` — exit 0, 31 юнит-тест, проверка типов
623 известные находки / 0 новых / 0 мёртвых.

| # | Что сделано |
|---|---|
| A22 | Таймаут админ-панели останавливает ожидание: поток `InvokeServer` отменяется через `task.cancel`, интерфейс больше не ждёт ответа сервера. Поиск remote перенесён внутрь потока, панель не ждёт его на главном потоке |
| A23 | `unmount()` защищён флагом от повторного входа: `created.Destroying → unmount()` больше не вызывает сам себя |
| A24 | Модалка позиционируется в одном месте (`shell()`): в портрете она центрируется в safe area и масштабируется под неё, в ландшафте остаётся на проектном месте доски. Проверено измерением: портрет `Modal` 385×270 (scale 0.592), ландшафт 650×455 в точке (315, 132) |
| A25 | Журнал сервера больше не хранит сырые сообщения: маскирование UserId идёт при записи, выход маскирует ещё раз для идентификаторов, известных позже |
| A26 | `Admin` RemoteFunction создаётся сервером только вместе с авторизованным игроком; клиент ждёт его до 5 с (`Net.adminClient`). Обычный клиент поверхности админа не видит |
| A27 | Питомец ищется по индексу до удаления: список не меняется во время чтения |
| A30 | `Economy.shotRatio` с целью 0, меньше нуля или NaN даёт внятную ошибку вместо молчаливого полного броска |
| A31 | `Economy.shotDistance` держит нижнюю границу: маршрут короче этажа не укорачивает бросок |
| A32 | `petDescriptor` и `petDescriptors` типизированы (`Economy.PetSource`): опечатка в имени поля больше не проходит молча |
| A37 | Починены проверочные скрипты Studio: мок состояния в `VerifyAdminIsolation` и `VerifyAdminPetCatalog` не имел `inventoryVersion`; клоны `GameConfig` в `VerifyRebirthProgression`, `VerifyWorldShotProgression` и `VerifyBiomeLengthExpansion` создавались вне папки пакета, и относительный `require ./Core/Economy` не резолвился; пробы пола в `VerifyBiomeLengthExpansion` считались по старой раскладке, где река стояла по центру коридора |
| — | Ложная ошибка диагностики «Щель у биома 1» убрана: атрибуты маршрута (`RouteFrontZ`, `RouteEndZ`, `RouteLengthStuds`) читаются из самих блоков воды (`BiomeLengthExpansion.refresh`), поэтому сцена после правок не расходится с описанием |

Проверено в Studio 21.10.2026 через симулятор устройств (iPhone 17 Pro, портрет 401×778 и
ландшафт 750×381): админ-панель открывается по F2 в обеих ориентациях и отвечает на `Status`,
модалка стоит в safe area, диагностика сцены проходит (кроме пунктов без продуктов), ошибок
от кода игры в Output нет. Подробности — в `docs/verification.md`.

Три находки, найденные при этой проверке, в аудит не входят и были исправлены в тот же
день: две вкладки навигации уходили за экран в портрете, верхний ряд HUD уходил под топбар
Roblox, админ-лаунчер перекрывал подпись «HIT: 60 m». Исправления и измерения — в
`docs/verification.md` и `docs/backlog.md`.
