# Decorated eggs: original colours

Source: ../DecoratedEggs15.fbx, originally exported from Downloads/йца за роблоксы.blend.
15 eggs; 75,498 triangles. The original material colours are transferred to per-face vertex colours for the current Studio preview.

Persistent import: DecoratedEggs15-OriginalColors.fbx contains a shared embedded palette texture, with UVs remapped by source material. Import through Studio 3D Importer with textures enabled. Keep original-palette.png beside the FBX as fallback.

The current Workspace.DecoratedEggs15 uses temporary EditableMesh content. Do not rely on this preview surviving Studio restart or publication. The connected Studio API reports CreateAssetAsync and CreateAssetVersionAsync are not available yet. No mesh assets were uploaded.

The original scene is backed up in ServerStorage.WorldBackups.DecoratedEggs15_BeforeColorRestore_20261021. Existing positions, sizes and collision flags were verified unchanged for all 15 eggs.
