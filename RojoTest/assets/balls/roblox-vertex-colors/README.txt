Импортируйте AllBalls_NoTextures.fbx через 3D Importer.
В этой версии цвета записаны в вершины: PNG и загрузка base_color_texture не нужны.
После импорта MeshPart.Color должен быть белым: 255, 255, 255.
Для Ball_03_CrystalIce_Shell и Ball_10_WorldCreator_Shell установите Transparency=0.74.
Мелкий резиновый рельеф первого мяча не переносится; основные цвета и швы сохранены приблизительно.
Файл проверен повторным импортом в Blender. Импорт в Roblox Studio пока не проверен.
